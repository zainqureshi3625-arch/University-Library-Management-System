# Traceability Matrix

University Library Management System

## 1. What is This?

This table connects each **requirement** to the **stakeholder need** it comes from, the **user story** that covers it, and the **acceptance criteria** or **check** that tests it. It shows that nothing is forgotten.

- **SN** = stakeholder need, **US** = user story, **AC** = acceptance criteria
- **Check** = the measurable check of a non-functional requirement (in `requirements-list.md`)
