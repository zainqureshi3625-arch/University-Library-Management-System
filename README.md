# University Library Management System

> A software engineering project to plan and design a new Library Management System (LMS) for a university library.

## Project Overview
The library keeps records of books, borrowing, returns, students and overdue books by hand or with an old system. This project plans an LMS that makes these tasks easier and more accurate. The team works like a real software team: it plans the work, writes the requirements, draws UML diagrams and designs a clickable UI prototype. The full working system is not built.

## Planned Features
- Book and book copy records, with search and availability
- Library member records
- Borrowing and returning books
- Book reservations
- Alerts for overdue books

## Users
- **Students:** search for books, see book details and reserve books
- **Librarians:** manage book records, give out books, take returns and check overdue books
- **Faculty members:** search for and borrow books
- **Administrators:** manage library information and watch over the system

## Objectives
- Make it easier to manage books, members, borrowing, returns, reservations and overdue books
- Reduce manual work, save time and make records more correct
- Practise Git, GitHub and working as a team

## Scope
- **Included:** project planning, requirements, UML diagrams and a clickable UI prototype
- **Not included:** the full working software, online payment, barcode scanning and mobile apps

## Assumptions
- All members have GitHub accounts, computers and internet
- Every member takes part and finishes his tasks
- The university gives the requirements and deadlines

## Constraints
- Time is limited and deadlines are set by the teacher
- Git and GitHub must be used
- Three team members share the work
- The full working system is not built

## Tools
- **Git and GitHub:** version control, teamwork and task tracking (Issues)
- **Markdown:** project documents such as this README
- **Spreadsheet tool:** schedule and planning tables
- **diagrams.net and Figma:** UML diagrams and UI prototype
