# University Library Management System

## 1. Introduction
The University Library Management System is a Software Engineering project designed to organize and manage university library activities.

## 2. Project Objectives
- Manage books and library records.
- Maintain student and librarian information.
- Make searching for books easier.
- Record book issuing and returning.
- Keep library information organized.

## 3. Project Scope
The system will help librarians manage book records, track issued and returned books, and help students find available books.

## 4. Assumptions
- Students and librarians will use the system.
- Book information will be entered correctly.
- Users will have basic computer knowledge.

## 5. Constraints
- The project must be completed within the assigned time.
- A computer and suitable software are required.
- Only authorized users should manage library records.
